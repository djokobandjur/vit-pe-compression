## Separation from the editorial source layer

The final Main/Supplement formatting and Editorial Manager source trees are editorial derivatives of the scientific master. They remain outside the Zenodo scientific archive. This prevents a circularity in which a DOI would have to be inserted into source files that were already frozen inside the DOI-bearing replication deposit.

## Zenodo workflow

Create a **manual new version** of the existing Zenodo record and upload the exact archive above. Reserve the v2.0.0 DOI in the Zenodo draft before final manuscript submission, then insert that DOI into the repository citation metadata and the manuscript Data and code availability statements.

Do not rely on an attached GitHub release asset being copied into Zenodo by the GitHub integration: Zenodo archives the repository source snapshot, while automatic inclusion of extra GitHub release assets remains an open feature request. To avoid a duplicate/incomplete source-only Zenodo version, disable the repository's automatic GitHub→Zenodo release ingestion while the manual v2.0.0 record is being created.

The Zenodo record should use the two authors above, version `2.0.0`, publication date `2026-09-07`, and mixed-license rights consistent with `LICENSE_SCOPE.md`.
